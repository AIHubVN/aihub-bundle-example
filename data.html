Data Format

Each dataset has the following folder structure. The img folder contains the images and the ann folder contains the segmentation masks. The subfolders train and val are the train set and validation set respectively.

--- img

     |--- train

     |--- val

--- ann

     |--- train

     |--- val

 

The image in the img folder has a corresponding mask in the ann folder with the same file name but different extension (jpg vs png).

For example, the image file /img/train/DJI_0008_1.JPG has the corresponding mask  /ann/train/DJI_0008_1.png

The images and masks can be loaded with standard libraries such as Pillow in Python. The masks are binary masks with 0 = background and 1 = high vegetation
